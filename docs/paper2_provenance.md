# Paper 2 provenance

Generated by `scripts/paper2/provenance.py` from the layout lists, the runs' `optimize_log.json`, the score JSONs and the job-history snapshot in `/n/holylfs05/LABS/arguelles_delgado_lab/Everyone/zdimitrov/tmp_rings/res2`. Repository: TambOpt, branch `cleanup`.

## Code

| Script | Role |
|---|---|
| `scripts/04_optimize_lbfgs_kernel.py` | Stage 4 layout optimisation (Adam / SGD, optional L-BFGS polish); kernel or surrogate response; utility chosen by TAMBOPT_UTILITY and related environment variables; writes <RUN>/test_v6_run_04_optimize_lbfgs_kernel_<suffix>/{layout_best.pt, optimize_log.json, opt_state.pt}. --pool c8 / --recon-type analytic added for the CORSIKA 8 + analytical runs (c8ana_*) |
| `scripts/03_train_recon_deepsets.py` | DeepSets reconstruction (<RUN>/test_v6_run_03_recentered_deepsets) |
| `scripts/paper2/ft_c8.py` | fine-tune of the run's DeepSets on CORSIKA 8 training showers -> tmp_rings/c8ft/ft19, ft20 |
| `scripts/paper2/score_all.py` | scores layouts on held-out showers (noise-free kernel): flow matching (default) or CORSIKA 8 test showers (SRC=c8), DeepSets (RECON_DIR) or analytical v1/v2/v3 (RECO, ANA_HIT=mu), background (BG_NS + kNN gate) -> score JSONs in tmp_rings/res2 |
| `scripts/paper2/trigsel.py` | triggered view: Malata accuracies over triggered showers, 12 km over all showers |
| `modules/optimize/analytic_reco.py` | TamboDirReco port (v1, v2, v3) used by score_all.py RECO=... |
| `modules/optimize/analytic_diff.py` | differentiable v1 (Gauss-Newton) for --recon-type analytic |
| `scripts/paper2/make_tables.py` | every table (complete LaTeX) and the layout / constraint figures -> Overleaf tables_2/, figures/results_2/ |
| `scripts/paper2/plot_exp.py` | sweep figures exp19 / exp20 and their layout figures |
| `scripts/paper2/make_paper2.sh` | driver: make_tables.py + plot_exp.py into the Overleaf clone |
| `scripts/paper2/check_paper2.sh` | compile check of the chapters at the journal page size |
| `scripts/paper2/provenance.py` | this file |
